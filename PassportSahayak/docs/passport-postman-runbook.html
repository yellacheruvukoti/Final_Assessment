Postman Runbook · API Gateway :9080

PassportSahayak API Runbook

Every endpoint written out the same way: the exact method, URL, headers and body you type into Postman on the left — the response you should see on the right. Base URL for everything is http://localhost:9080/api.

§

Before you start

  1. Start the API Gateway and all 8 microservices (mvn spring-boot:run in each).
  2. Open Postman → New → HTTP Request.
  3. Sanity check first — set method GET, URL http://localhost:9080/api/centers, no headers, no body → Send. If you get a list of 7 passport centers, the gateway is up and you can start on section 0.

How to type a body. Click the Body tab → choose raw → in the dropdown on the right pick JSON → paste the JSON. If a request says "Body: none", leave that tab on none.

How to type the token. Click the Headers tab, add a row with key Authorization and value Bearer <paste-token-here>. There is one space after "Bearer" and no quotes around the token.

§

Values you carry between requests

Four values come out of one response and go into the next. Copy them as you go (or let the collection's test scripts save them for you).

ValueComes fromUsed by
tokenLogin – ApplicantAll applicant requests
officialTokenLogin – OfficialEverything marked [Official]
adminTokenLogin – AdminAll Knowledge Base requests
arnCreate applicationAppointments, PV, grievances, appeals
appointmentIdBook appointmentReschedule, cancel, complete, no-show
documentIdIngest KB documentKB document + chunk requests

Sample values used throughout this page: ARN PS1787580143454, appointment id 1, center id 1, document id e4b88084-581d-4d39-98a5-b48084a22059. Yours will differ — substitute your own.

§

Authorization — which token for which request

Three roles, three different tokens. Every request below is listed with the exact one it needs. Getting this wrong is the difference between 200 OK and 403 Forbidden.

Typing it the long way (Headers tab): add key Authorization, value Bearer eyJhbGciOiJIUzUxMiJ9... — one space after "Bearer", no quotes, no angle brackets.

Typing it the short way (Auth tab): click Authorization tab → Type = Bearer Token → paste only the token into the Token box. Postman writes the header for you. Do not type the word "Bearer" here.

Two mistakes that produce 401 every time: pasting the token with the surrounding quotes from the JSON response, and forgetting the space after Bearer. The token itself has no spaces — it is three dot-separated chunks.

And one that produces 403: the applicant token on an [Official] route. The token is valid; the role isn't.
